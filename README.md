# ModelInspector - 纯前端单页面 AI 模型能力检测平台

OpenAI 兼容接口模型能力检测工具，**100% 纯前端浏览器直接运行（纯静态单页面应用）**，已完全本地化所有静态依赖（JS/CSS/字体/图标全部离线可用，无需担心 CDN 失效或网络受限），无需任何后端服务（无需 Node.js / Python / 任何构建与编译），直接在浏览器双击打开 [`index.html`](file:///D:/work/web_projects/model_check/index.html) 即可使用。

   - **生图参数可在页面按需配置（极简默认，兼容所有大模型与中转接口）**：
     - **提示词 (Prompt)**：默认预设 `一只戴着复古墨镜在赛博朋克霓虹街头滑板的柴犬，电影级光影，8k高分辨率壁纸`（支持自定义与一键重置）。

     - **按需扩展参数**：
       - **图片尺寸 (Size)**：默认不传（使用模型缺省尺寸）；可选 `1024x1024`、`512x512`、`768x768`、`1792x1024`、`1024x1792`、`1536x1024`、`1024x1536`。

       - **风格 (Style)**：默认不传（兼容所有模型）；专为 DALL-E 3 可选 `vivid` 与 `natural`。
       - **返回格式 (Response Format)**：默认不传（自适应服务端返回的 URL 或 Base64）；可选显式指定 `url` 或 `b64_json`。
       - **生成张数 (N)**：默认 1 张（不传参，仅在设为大于 1 时向接口传递）。
   - **图片编辑精简传参与自定义换图**：

2. **🎯 整合 LM-Detector 模型指纹识别 (深度识别 API 真实模型)**：
   - **背景**：中转站或第三方 API 常声称提供某个顶级模型，实际底层可能被降级或偷换成廉价模型。

   - **基础连通检测联动**：
     - 勾选「连通/指纹 (Chat)」后，自动向模型发送指纹探针提示词（支持在侧边栏「🎲 随机换题」与「↺ 恢复默认」自定义编辑）。
     - 只要模型接口连通并返回回答，基础对话即判定通过；同时自动运行纯前端指纹提取与评分计算。
     - **模型可能性排行**：在表格气泡与卡片视图中实时标注最匹配的真实模型及置信度（如 `Claude 3.5 Sonnet (98.2%)` 或 `gpt-4o (96.8%)`）。
     - **全维度指纹诊断抽屉**：点击对话气泡即可弹出查看：
       - 🎯 **最可能匹配模型** 与相对置信度；

       - 🔬 **伪随机序列统计诊断**（Lag-1 一阶自相关性、小步长变化占比、模型伪随机特征吻合度）；

## 💡 深度严格判定原理

- **动态拉取模型**：`GET {BaseURL}/models`，自动解析 `data[].id` 或数组格式。
- **思考输出 (Thinking)**：向 `/chat/completions` 发送高难度推理问题，携带 `reasoning_effort`（默认 high），严格提取 `reasoning_content` 及 `<think>` 标签，统计思考过程长度。
- **全局 Token 长度与鹈鹕单车**：所有请求默认设置 `max_tokens=65536`（64K，可在左栏设置 0-n，设为 0 时不传），避免思考链或长 SVG/H5 代码被截断导致误判。
- **请求参数**：默认携带 `max_tokens=65536`（64K），只发送核心参数（`model`、`messages`，按维度补充 `stream`/`tools`/`reasoning_effort`），不发送 `temperature`、`top_p` 等采样参数。
- **流式兼容**：返回 SSE 时按 `data:` 增量合并后再判定；中转站忽略 `stream` 返回 JSON 时同样可解析。
- **并发调度**：任务按「模型 × 检测维度」拆入任务池，并发数默认 1（串行），可调大；设为 5 时单模型的 5 个维度会同时发起，多模型时最多同时进行 5 个请求。
- **视觉能力 (Vision)**：向 `/chat/completions` 发送动态 Canvas 绘制的 64x64 高对比纯红底色与中心蓝圆图样，排查过滤 20 余种“无法查看图片”的中转拒答假阳性，模型必须识别出色块真值方可判定支持。
- **工具调用 (Tools)**：向 `/chat/completions` 发送标准 `tools` 函数定义，深入解析服务端返回的 `tool_calls` 结构体及参数有效性，严格区分“原生结构化支持”、“仅文本模拟”与“不支持”。
- **鹈鹕骑单车 (Pelican)**：向 `/chat/completions` 发送 SVG 动画生成指令，严格分析返回文本中是否包含有效的 SVG 标签及动画关键帧，并提供一键渲染沙箱。
